## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to `/output/entry.png`, so both graded runs write identical bytes with no network. `draw_news_image.py` is the Pillow script that drew `entry.png` (1024×1024, 131,236 bytes).
